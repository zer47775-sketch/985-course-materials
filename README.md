# 985高校三门课程资料

本仓库提供高等数学、线性代数、大学物理资料的索引和下载说明。
资料包放在本仓库的 **Releases** 页面，按课程选择下载。

| 课程 | 资料数 | Releases 附件 |
|---|---:|---|
| 高等数学 | 2377 | `01-calculus-985.zip` |
| 线性代数 | 902 | `02-linear-algebra-985.zip` |
| 大学物理 | 858 | `03-university-physics-985.zip` |

总计4137份，原文件合计3,515,991,542字节。学校按清北、其他C9、其他985安排处理；同层编号不代表校际排名。

## 使用

1. 到本仓库 Releases 页面下载三份 ZIP；只需一门课也可单独下载对应包。
2. 三包解压到同一位置，合并共同的「高校课程资料」文件夹。
3. 重复的说明、索引与 JSON 文件内容相同，保留任意一份即可。
4. 用浏览器打开解压后的「资料索引.html」，搜索学校、课程和文件名并打开本地资料。

索引是离线相对路径索引；只解压一门课时，其他两门的本地链接需要对应课程包。
下载后可用仓库提供的 SHA256SUMS.txt 校验 ZIP。
